# BLACK PREMIUM — Telegram Shop Bot

Универсальный Telegram-бот-магазин на Python + aiogram 3 + SQLite.

## Возможности
- Каталог товаров, описание, цена и фото по URL.
- Корзина с количеством товаров.
- Оформление заказа с именем и контактом покупателя.
- Уведомления администраторам о новых заказах.
- История заказов пользователя.
- Админ-команды для добавления/скрытия товаров и просмотра заказов.
- Переключение RU/EN.
- Локальная база SQLite.

## Важно про оплату
В этой первой версии бот принимает **заявку на заказ**, а не списывает деньги автоматически.
Администратор связывается с покупателем и согласует оплату. Это позволяет протестировать магазин без привязки платёжного провайдера.
Для цифровых товаров внутри Telegram обычно требуется Telegram Stars (XTR); для физических товаров применяются поддерживаемые платёжные провайдеры. Интеграцию добавим после выбора типа товаров и страны продавца.

## Запуск на Windows
1. Установи Python 3.11 или новее с python.org (при установке отметь "Add Python to PATH").
2. Распакуй архив.
3. Открой папку `black_premium_bot`.
4. Скопируй `.env.example` в `.env`.
5. Заполни `BOT_TOKEN`, `ADMIN_IDS` и `SUPPORT_USERNAME`.
6. Открой терминал в папке и выполни:

```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

## Запуск на macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## Настройка Telegram
1. В Telegram открой официального `@BotFather`.
2. Отправь `/newbot`, задай имя и username.
3. Скопируй токен в `.env` после `BOT_TOKEN=`.
4. Узнай свой Telegram ID через надёжный ID-бот/инструмент и впиши его в `ADMIN_IDS=`.
   Несколько ID можно указать через запятую.
5. Запусти бота и отправь ему `/start`.

**Никогда не публикуй токен и не отправляй его в этот чат.** Если токен случайно раскрыт, отзови его через BotFather командой `/revoke`.

## Команды администратора
- `/admin` — справка.
- `/addproduct Название|Цена|Описание|Фото_URL` — добавить товар. Фото URL необязательно.
- `/products` — список активных товаров.
- `/delproduct ID` — скрыть товар.
- `/orders` — последние 15 заказов.
- `/paid ID` — отметить заказ оплаченным и уведомить покупателя.

Пример:
`/addproduct Чёрная футболка|19.90|Плотный хлопок, размеры S–XL|https://example.com/photo.jpg`

Цены в примере указаны в евро и являются только отображением. Реальную валюту и налоговые требования нужно настроить под бизнес продавца.

## Перед продажей клиентам
Это стартовый MVP, а не готовая к масштабированию платёжная платформа. Перед коммерческим запуском нужно:
- настроить хостинг 24/7 и резервные копии базы;
- добавить настоящую оплату под тип товара и страну;
- проверить обработку персональных данных, возвраты, налоги и условия продажи;
- добавить защиту от спама и лимиты;
- заменить название, тексты, валюту и контакты под клиента.
